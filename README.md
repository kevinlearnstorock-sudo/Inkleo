# Inkleo

> A minimalist, high-performance screen annotation tool designed for Windows.

---

## 📌 Project Overview
Inkleo is a modern presentation and screen-sharing companion. It provides a lightweight, zero-latency drawing overlay that allows users to sketch, highlight, and annotate directly over any active Windows application.

## 🚀 Key Intentions
- **Minimalist Design:** No clunky toolbars, just pure drawing efficiency.
- **High Performance:** Smooth rendering and instant shortcut switching, built specifically for Windows.
- **Store Ready:** Optimizing for a clean, stable release on the Microsoft Store.

## 📅 Status
- **Current Phase:** Pre-alpha / Active Architectural Design.
- All core branding, naming, and repository identity have been established.
